# 登録なしで使える入口（2026-10-04）

## 利用者の流れ

- トップは「登録せずに使う」を最初に提示。その下に、記録を別端末へ引き継ぐためのGoogleログインと既存メールログインを置く。
- `/guest` はサンプルのない実地図と、既存の「地図・書く・ノート」を使用する。アカウント作成や認証API呼び出しなしで、メモと下書きをそのブラウザー内に保存する。
- 「保存先：このブラウザー」を常時表示。別端末・別ブラウザーとは共有されず、閲覧データの削除や端末故障で失う可能性を説明する。位置情報は操作時だけ取得する。
- ノートで検索、読み返し、編集、削除、全件JSON書き出しができる。保存の説明を開くと、旧デモからのコピーと、このブラウザーの記録・下書きの全削除ができる。全削除は確認付きで、アカウントの記録・旧デモには触れない。
- `/demo` は以前のデモとして維持。旧デモの自作メモは明示操作で `/guest` へコピーできる。`sample-*` の架空データは除き、元の作成日時と元データを保つ。

## Googleへの引き継ぎ

- Googleや既存メールでログイン後、端末に記録があれば引き継ぎパネルを表示。自動では送信しない。
- 引き継ぎ先のメールアドレスと対象の一覧を表示し、自分の記録であること・引き継ぎ先を確認したチェック後に送信する。
- コピー方式。元の端末のメモと下書きは削除しない。コピー後の端末側とアカウント側は別々の記録で、自動同期はしないと説明する。
- 保存済みのメモだけが対象。下書きは先にメモとして保存する。旧デモの記録は先にゲストノートへコピーする。
- アカウントID・ローカルのメモID・バージョンごとに引き継ぎ操作IDをIndexedDBに先に保存する。応答喪失や再読み込み後は同じ操作IDでPOSTし、既存APIの冪等性を利用して重複を避ける。
- 完了済みの同一バージョンは再送しない。端末で編集した新しいバージョンを後日引き継ぐと新しいコピーになる。アカウント側で変更した記録は上書きしない。
- 書き込みの各リクエストで、確認済みのアカウントIDと現在のセッションIDを比較する。別アカウントに切り替わった場合は送信を停止する。
- 引き継ぎ中はゲスト編集と同じWeb Lockを取得する。他のタブでゲストノートを開いている場合は、閉じてから再試行を案内する。プレビュー後に変更・削除された記録は再確認を求める。

## 保存と互換性

- ゲスト記録：IndexedDB `machinote-guest` の `memos`。引き継ぎ状態：同DBの `imports`。ゲスト下書きは既存の下書きDBで `browser-guest` 所有として分離する。
- 記録の更新は単一IndexedDBトランザクション。容量不足などで保存できないときは成功表示せず、下書きを残す。読み込めない記録を空配列で上書きしない。
- 既存のアカウント用API/RLSを維持。ゲストが直接サーバーのメモを読み書きする経路は追加しない。Google Mapsの利用も追加しない。
- 日付を保つため、認証済みPOSTで `X-Memo-Created-At` のISO日時を受け付ける。未来日時などを拒否し、所有者は認証セッションから決定する。既存の `created_at` 列を使うため、DBマイグレーションは不要。
- 引き継ぎ後のリスト・地図は再取得するだけで、編集中のノートを破棄・再マウントしない。
- この変更に伴い、書く画面の「下書きのまま閉じる」でも進行中のGPS結果を無効化し、閉じた後に場所が変わらないよう統一した。
- 復帰点はGitタグ `before-guest-entry-20261004`。旧デモ・旧本番 `/classic`・従来のデータを保持する。

## 検証

ローカルの単体/API/DBテストと、外部通信をモックしたブラウザーテストで検証する。新規項目は、登録不要の保存・再表示・編集・全削除、旧デモのサンプル除外と日付維持、コピー前の確認、通信失敗後の引き継ぎ再試行・重複防止・原本保持、容量不足時の下書き保持、アカウント変更時の送信拒否。スマホ幅の入口・地図・ノートの画像も確認する。

端末内のメモは暗号化された個人用金庫ではない。同じ端末・ブラウザーを使う人には読めるため、共用端末向けの説明と削除手段を用意する。ファイル書き出しにはメモと場所が含まれる。Googleへの引き継ぎは任意で、ブラウザーの保存データを消す前に行う。
