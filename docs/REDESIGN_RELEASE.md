# ノートの表示・管理と1件削除（2026-10-05）

承認済みの [画面設計](design/2026-10-05-experience-plan.md) を実装。変更前は `e7ddb6c`、復帰用タグは `before-notebook-redesign-20261005`。旧デモ `/demo` と旧画面 `/classic` を残す。DBスキーマ・保存済みの記録・認証設定は変更しない。

## 利用者から見える変更

- 共通ヘッダーの「メニュー」に保存先・アカウント、記録の管理、ヘルプを集約。下部は「地図・書く・ノート」の3操作を維持。
- 普段は保存先を1行で表示。ゲストの詳しい説明は閉じられ、保存先を押すと再確認できる。引き継ぎ待ちの記録がある場合だけ短い案内を表示する。
- ノートは日付と本文が中心。JSON出力・旧デモの取り込み・全削除は「記録の管理」へ移動。ダウンロードは検索結果に限定せず、表示中の保存先の全記録を対象とする。
- ノートの記録を左スワイプすると「削除」が現れる。日時・本文・保存先を確認して1件だけ削除。キャンセル時は元の記録へフォーカスを戻す。詳細の「この記録を削除」からも同じ確認へ進める。
- 深いスワイプでも即削除しない。縦スクロール・小さな横ぶれ・画面端を考慮し、開く操作は1件だけ。下書き・編集ロック・保存中は削除を開始できない。
- 現在地ボタンを地図内へ移動。「地図の中央を選ぶ」は場所選択中に表示し、キーボード操作を維持する。
- ブランドと記録本文は明朝、操作や説明はゴシック。記録の枠を抑え、余白と日付で区切る。メニューはスマートフォンでは下部シート、広い画面では右側パネル。
- 未ログインでも `/help` で保存先、引き継ぎ、現在地、削除などの説明を読める。

## 保存と失敗時の扱い

削除は既存の記録ID・versionを使うAPIと端末保存処理を通す。成功前に一覧から消さない。結果不明の操作は端末の下書きに保全し、再読み込み後も結果確認・再試行できる。409競合は成功扱いにせず、更新済みの記録を残す。

メニューを開閉しても地図・一覧をアンマウントせず、検索や書きかけを維持する。引き継ぎは従来どおり対象とアカウントの確認後にコピーし、元の端末記録を保持する。
